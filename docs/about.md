# 品牌介紹

Soft Jewelry Studio 是以項鍊設計為核心的珠寶品牌網站。現階段以靜態展示、3D 檢視與 AR 試戴作為 MVP，讓訪客能先理解作品氣質，再進一步討論客製方向。

## 設計理念

我們偏好柔和、乾淨、能長時間配戴的線條。每一條項鍊都應該能回應一個日常情境：送禮、紀念、陪伴，或只是讓自己在某一天多一點光。

設計時會優先考慮：

- 配戴比例是否自然。
- 吊墜與鍊條是否平衡。
- 寶石顏色與寓意是否貼合使用者需求。
- 作品能否在日常穿搭中穩定出現，而不只適合拍照。

## 材質選擇

目前網站以銀色、金色、玫瑰金、珍珠與寶石元素作為展示方向。正式製作前，仍需要依預算、過敏風險、保養習慣與配戴頻率確認材質。

常見討論方向：

- 鍊條：細鍊、蛇骨鍊或更有存在感的鏈型。
- 吊墜：圓形、月亮、愛心、星形或客製符號。
- 寶石：藍寶石、粉色寶石、綠色寶石、小鑽石、珍珠。
- 色系：銀色清爽、金色溫暖、玫瑰金柔和。

## 客製流程

1. 選擇想要的項鍊基礎款式。
2. 在 3D 設計工作台嘗試寶石、吊墜與排列方向。
3. 使用 AR 試戴確認配戴位置、大小與整體氣質。
4. 整理需求後進行詢問，包含用途、預算、材質偏好與交付時間。
5. 確認設計方向後，再進入製作或後續細節調整。

## 保養方式

珠寶日常保養會直接影響光澤與使用壽命。建議依材質採取對應方式，並養成配戴後簡單清潔的習慣。

- 避免長時間接觸香水、酒精、汗水與清潔劑。
- 洗澡、泡溫泉、運動與睡覺前建議取下。
- 配戴後以柔軟乾布輕拭，再放入夾鏈袋或飾品盒。
- 珍珠與鍍層材質不要使用粗糙拭布或強力清潔液。
- 若有寶石鬆動、鍊扣變形或金屬變色，應先停止配戴並詢問維修方式。
